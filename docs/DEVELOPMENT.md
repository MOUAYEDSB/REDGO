# Development

## Requirements

- Node.js and npm.
- Expo tooling for mobile applications.
- Supabase CLI for backend services.

## Commands

Run frontend workspace commands with npm:

```powershell
npm install --prefix front
npm run lint --prefix front
npm run typecheck --prefix front
npm run build --prefix front
```

Phase 0 validation is limited to installation, lint, type checking, and builds. Business features should begin only after Phase 0 approval.
